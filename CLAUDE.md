# claude-architect-foundations

Training repo for the CCAR-F certification exam. Each weekN-* folder is a
standalone exercise area; notes/ holds end-of-week summary notes.

## Universal conventions
- All code, comments, filenames, and commit messages are in English.
- Python 3.12 with the repo-local virtual environment (.venv); activate it before running scripts.
- Commit message format: "weekN: <short imperative summary>".
- Never hardcode secrets; read API keys from environment variables (e.g. ANTHROPIC_API_KEY).
- Update PROGRESS.md at the end of every working session.
